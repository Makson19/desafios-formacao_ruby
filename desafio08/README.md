# Desafio Ruby com Nokogiri

## Objetivo

Este desafio tem como objetivo praticar web scraping em Ruby utilizando a gem Nokogiri.

A proposta consiste em acessar o HTML do site `https://example.com` e retornar o conteúdo existente dentro da tag `<p>`.

---

## Tecnologias utilizadas

- Ruby
- Nokogiri
- Net/http

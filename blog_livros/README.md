# 📚 Blog de Livros - Ruby on Rails

## 📖 Sobre o Projeto

Este projeto foi desenvolvido utilizando Ruby on Rails.

O objetivo do sistema é funcionar como um blog pessoal de livros lidos durante o ano, permitindo cadastrar informações importantes sobre cada leitura.

O sistema possui funcionalidades básicas de CRUD:

- Criar livros
- Listar livros
- Editar livros
- Excluir livros

---

# 🚀 Tecnologias Utilizadas

- Ruby
- Ruby on Rails
- SQLite3
- HTML

---

# ⚙️ Como Executar o Projeto

## 1. Clonar o repositório

```bash
git clone git@github.com:Makson19/desafios-formacao_ruby.git
```

## 2. Entrar na pasta do projeto

```bash
cd blog_livros
```

## 3. Instalar as dependências

```bash
bundle install
```

## 4. Executar as migrations

```bash
rails db:migrate
```

## 5. Iniciar o servidor

```bash
rails s
```

## 6. Abrir o navegador

```bash
http://localhost:3000
```
